# Clipboard History

What you copied, back with one shortcut — modelled on Raycast's clipboard
history. Press **⌘⌃⇧V** anywhere, type to filter, ↑↓ to pick, **Return** to
paste it into the app you were in.

It lives entirely in the desktop shell (`apps/desktop/src-tauri/src/clipboard/`):
capture, storage, search and paste never touch the daemon. See
[Privacy](#privacy).

## Setup

1. **Turn it on.** It is off until you do. Press ⌘⌃⇧V and choose **Turn on**,
   or Settings → **Clipboard history** → **Turn on**.
2. **Paste from Other Apps (macOS 15.4 and later).** macOS asks the first time
   Otto reads the clipboard after you turn it on. After that, open System
   Settings → Privacy & Security → **Paste from Other Apps** and set Otto to
   **Allow**. While it is set to *Ask* or *Deny*, Otto reads nothing (an *Ask*
   would pop an alert at every copy) and the panel says so with an **Open
   System Settings** button.
3. **Accessibility (optional, for Return to paste).** To paste for you Otto
   presses ⌘V in the app in front, which needs System Settings → Privacy &
   Security → **Accessibility** for Otto. Without it Return copies the entry
   and the panel says "Copied. To paste for you, Otto needs Accessibility" with
   a button that opens that pane (Otto is added to the list).

## Walkthrough

1. Copy as usual in any app. Otto checks the pasteboard about every 0.75 s and
   records plain text, rich text (as text), links, file references (the paths,
   never the file contents) and images, with the app that was in front, the
   size, image dimensions, when it was first and last copied and how many times.
   Copying the same thing again moves it to the top and bumps **Times copied**.
2. **⌘⌃⇧V** opens the panel over the app you are in (it doesn't bring Otto's
   windows forward). Change the chord in Settings → Clipboard history.
3. **Filter** — type to match text, file names/paths and the source app's
   name; the **All Types** menu narrows to Text, Images, Files or Links.
   Entries are grouped Pinned, Today, Yesterday, then by date.
4. **Preview** — the right side shows the text or image and its Information:
   Source, Type, Dimensions (images), Size, Times copied, Last copied.
5. **Return** pastes into the app you were in ("Paste to Safari"). **⌘K**
   opens Actions: Paste, Copy to Clipboard, Pin / Unpin, Delete Entry, Pause /
   Resume Capture, Clear History…. **Esc** or clicking elsewhere closes it.

## Capabilities and limits

- Kept: the newest 500 unpinned entries from the last 30 days, and unpinned
  images up to 512 MB in total (oldest first out). Pinned entries are kept
  until you unpin or delete them.
- Skipped, not truncated: text over 256 KB, images over 25 MB.
- Never recorded: copies marked concealed, transient or auto-generated by their
  app (`org.nspasteboard.ConcealedType` / `TransientType` /
  `AutoGeneratedType` — what password managers set), and 1Password, KeeWeb,
  TypeIt4Me and similar password-manager types.
- Search folds ASCII case only; other scripts match as typed.
- The list shows up to 200 rows; type to narrow a longer history.
- ⌘V is sent with the ANSI **V** key code. A keyboard layout that moves V
  (Dvorak) may need the plain-copy fallback (⌘K → Copy to Clipboard, then
  your own paste).
- Desktop app only. There is no phone or browser version, and no sidebar page.

## Privacy

- **On this Mac only**, in `~/Library/Application Support/com.otto.app/clipboard/`
  (folders 0700, files 0600): `history.json`, `settings.json`, `images/`
  (PNG + thumbnail per image) and `icons/` (source-app icons).
- **Never shared** with agents, sessions, the daemon's HTTP API, MCP, the
  phone/remote surface, telemetry or logs. The shell has no daemon token and
  no network surface; the content commands answer only the panel window
  (`otto-clipboard`), so the main window (which agents can drive) gets status
  and settings, never entries; the panel page never signs in to the daemon.
- **Pause capture** stops recording (nothing copied while paused is read
  later). **Clear history** deletes every entry and image. **Turning it off
  deletes the history.**
- Window titles never show content (the panel is "Clipboard History").

## Troubleshooting

- **Nothing new shows up** — check the panel's banner: paused, or macOS's
  Paste from Other Apps is set to Ask or Deny for Otto (set it to Allow).
- **Return only copies** — grant Accessibility to Otto (button in the panel or
  Settings), then try again. A rebuilt or moved app may need it granted again.
- **The shortcut does nothing** — another app holds the chord; Settings →
  Clipboard history shows the error. Pick another chord there.
- **A password showed up** — its app doesn't mark copies as concealed. Delete
  the entry (⌘K → Delete Entry) and pause capture while copying secrets from
  that app.
