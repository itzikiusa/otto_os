## Limits and handoff

No findings were rejected. All assigned production repairs are authored; final integration and runtime verification remain with root. History wire shape remains compatible and unpaginated: metadata listing is O(number of versions), independent of historical body size. Backlink identity listing remains O(total incoming links), while expensive source context reads are bounded per request. Measured actual endpoint timing, CPU/RAM under concurrent agent load and light/dark/phone screenshots are not supplied by this agent.

Design publication is ordered within one daemon process across service instances. The durable version/blob is authoritative; filesystem mirror and derived indexing retain best-effort recovery semantics. SQLite and filesystem are not a distributed transaction, and cancellation/crash or I/O failure after the version commit can still require rebuilding derived state. No rollback of a successfully committed version is claimed. The weak registry does not coordinate two independent daemon processes against one data root.

The rename test executes the branch supported by the fixture volume. Default case-insensitive APFS does not prove the distinct-case collision branch; run on a case-sensitive disposable volume for that evidence. An external process occupying both the destination and original source during rollback leaves the preserved source at its reported temporary path rather than overwriting either file.
