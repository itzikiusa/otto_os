## Performance, architecture and limits

`evidence/R09-personal-fanout.json`: production store, deterministic1ms in-memory transport, Node22.22.3. At1/100/1000 agents, peak outstanding schedule requests changed1/100/1000→1/2/2. Total completion changed1.77/2.63/14.10ms→1.76/63.24/634.63ms. These are queue/concurrency measurements, **not network or rendering benchmarks**: preserving interactive socket capacity necessarily increases all-details completion time. Residual transport is N schedule + N autonomy requests; a future batched summary endpoint can reduce total work. Cards progressively acquire autonomy summaries.

Memory-file I/O is now O(min(file bytes,8000)) per accepted file, bounded160KB across20 memory inputs; the sparse64MiB fixture proves tail bytes are irrelevant. No unsupported wall-time speedup claim is made.

Thread HTTP/DOM work initially bounds100 rows. The new expression index should remove full-history sorting, checked with EXPLAIN in the state test. Offset pagination still traverses O(offset) index entries and represents live ordering: concurrent updates can cause duplicates/omissions across pages; UI deduplicates and refresh resets the page. It is not a snapshot-export API. Loaded pages grow only by explicit user request; selected older thread is held separately.

Architecture: existing `AssistantCtx`/`SwarmHost` boundaries retain testable engine/state/host separation. Reused mapLimit rather than adding another worker abstraction. Notification qualification remains an internal persisted hash (no schema/wire migration). Paging adds only an index and query options, retains array response and supports existing simple callers. No source-verified architecture blocker was found; large engine files alone were not reported as defects.

Explicit limits: no real provider turns, actual outbound delivery, live multi-user concurrency, crash/power-loss file-write injection, macOS webview profiling, exhaustive RTL/tablet traversal or all swarm visual routes were executed. General external filesystem write races beyond Remove rollback's atomic create-new remain outside this regression's guarantee; corrected the misleading TOCTOU comment rather than claiming immunity. Full repository coverage/integration signoff belongs to the coordinator.
