## Structure and test quality

The search repair moves SQL and match projection into the state layer, retaining permission decisions and response mapping in the server. This removes the endpoint's full-record loading and per-swarm fanout without creating an adapter hierarchy. The source enum keeps each SQL shape, kind and feature paired. Unicode matching intentionally remains a bounded streaming scan rather than switching semantics to SQLite's ASCII-only lowercase. Sorting can still require SQLite scan/sort work, especially at much higher cardinality.

Workbench ownership checks stay next to the operations that await, with one generation and request identity per resource. This avoids changing shared transport behavior for unrelated consumers. The UI uses existing shared components, tokens and error/Retry conventions; no stylistic redesign was introduced. New failure tests were run against the old implementation before fixes; this supplies mutation-like evidence for the actual defects, not a broad mutation-coverage percentage. Positive controls cover unchanged targets, root access, shared/owned memory and fragmented valid LSP frames.
