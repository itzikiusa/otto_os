## FI-01 — failed validation retries inflate the visible iteration score

**Major; confirmed by source trace and the coordinator's executed red regression; repaired in this iteration.** The pre-fix `crates/otto-server/src/skill_eval.rs:3174–3184` recomputed the retry's iteration score using only validators whose status is `done`. This was an existing adjacent inconsistency, not newly introduced by the campaign. The repaired multi-pass finalizer correctly made an incomplete validator `error`, with score 0; the retry aggregate then dropped that validator from both numerator and denominator.

Concrete reachable input: an iteration has validator A `done/100` and validator B whose two-pass retry returns one clean verdict and one malformed output. `finish_validation` produces B `error/0`; `set_iter_agent_at` persists B; the aggregate filter yields `[100]`, so `set_iter_score` persists 100. Initial generation's collector includes the errored result and would average `[100,0]` to 50. `ui/src/modules/skills-eval/RunDetail.svelte:476` and `:497` render `iteration.score` directly in the visible iteration badges, so a failed retry visibly appears perfect in those badges. The separate Review artifact and composite correctly record the failure; this finding is not a promotion bypass.

**Repair independently reread:** `crates/otto-server/src/eval_score.rs:61` now computes the mean over every configured validator, treating non-completed states as zero, inside `publish_validation_retry`'s existing evaluation update guard. The old caller block is removed. The extended `malformed_validation_cannot_publish_passed_review_evidence` regression calls the real publisher with mixed validator states and checks both persisted iteration score and published review signal; the Review artifact status is also asserted. I read the coordinator's `/tmp/quality-next-retry-badge-red-runtime.log`: the meaningful failing assertion was actual 100 versus expected 50. Its green seven-test run was compiling at final handoff; the coordinator's final integration record must supply that outcome. This reviewer did not execute the test.
