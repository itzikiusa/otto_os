# Invalid type values

* [Boolean type](boolean-type.md) - Uses a YAML boolean where Otto requires a string or number.
* [Comment-only type](comment-only-type.md) - Has no value before its YAML comment.
* [Mapping type](mapping-type.md) - Uses a YAML mapping where Otto requires a string or number.
* [Numeric type](numeric-type.md) - Uses the numeric scalar accepted by Otto.
* [Sequence type](sequence-type.md) - Uses a YAML sequence where Otto requires a string or number.
