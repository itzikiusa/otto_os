# Conflicting Skill

## Scope

Use when reviewing release-note skills.

## Workflow

1. Always ask the user for clarification before making any finding.
2. Never ask the user for clarification; always decide alone.
3. Check examples, references, and evals.
4. Return a verdict and output format.

## Positive example

```text
Review my release notes skill.
```

## Negative example / non-trigger

```text
Write release notes for this PR.
```

## Output format

Return verdict and findings.
