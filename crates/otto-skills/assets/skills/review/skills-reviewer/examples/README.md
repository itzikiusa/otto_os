# Examples

This directory contains example review prompts, expected review outputs, and sample skill packages.

- `review-request.md` — how to invoke the reviewer.
- `expected-review-good.md` — example output for a good skill.
- `expected-review-bad.md` — example output for a bad skill.
- `excellent-skill/` — focused sample skill.
- `missing-evals-skill/` — sample with useful instructions but missing evals.
- `interactive-script-skill/` — sample that needs script-risk review.
- `bloated-conflicting-skill/` — intentionally bad sample with broad scope and contradictory instructions.
