# Image assets

- `agents/*.webp` — personal-agent character avatars (192×192, one per personality).
- `mascot/*.webp` — the Otto mascot (320×320): `wave`, `thinking`, `celebrate`, `sleep`.

Generated for Otto with Meshy (text-to-image), 2026-11-05. Original artwork owned by the Otto project.

Imported as URLs (`?url`) from lazily loaded modules only, so Vite emits them as
files and they never land in the entry chunk.
